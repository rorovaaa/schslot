ПАПКА ДЛЯ ВАШИХ КАРТИНОК И ФОТОГРАФИЙ К ПРИЗАМ
=====================================================

Вы можете положить в эту папку любые свои картинки (PNG, JPG, WebP или GIF).
Программа автоматически подхватит их при запуске!

Имена файлов для каждого приза:
-----------------------------------------------------
1. Отмена двойки (5%):
   cancel_2.png   (или cancel_2.jpg / cancel_2.webp)

2. Пять в журнал (15%):
   grade_5.png    (или grade_5.jpg / grade_5.webp)

3. +1 балл к ответу (25%):
   plus_1.png     (или plus_1.jpg / plus_1.webp)

4. Отмена Д/З (25%):
   cancel_hw.png  (или cancel_hw.jpg / cancel_hw.webp)

5. Помощь друга (30%):
   friend_help.png (или friend_help.jpg / friend_help.webp)

Примечание:
Вы также можете загружать любые картинки прямо из интерфейса через меню «Учитель» (⚙️), нажав кнопку «Загрузить фото».
